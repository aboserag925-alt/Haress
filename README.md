# حارس — استراحة أهل الأثر

منصة عربية RTL للعلم الشرعي، بهوية بصرية موحدة ومستقلة V2.

## البنية
- `app/`: تطبيق الويب وأصوله الثابتة.
- `app/identity-tokens.css`: المصدر الوحيد لألوان الهوية والخطوط ورموز الوضعين الفاتح والداكن.
- `app/identity-v2.css`: مكونات الواجهة المشتركة للصفحة الرئيسية ولوحة الإدارة.
- `app/v3/v3.css`: تخطيط الواجهة التحريرية V3، ويستهلك الرموز المشتركة فقط.
- `src/worker/`: Cloudflare Worker.
- `supabase/`: ملفات المصدر والمهاجرات؛ لا تُشغّل migrations تلقائيًا.
- `server/`: خدمات Node.js المساندة.
- `assets/`: الأصول التشغيلية المشتركة فقط.

## الاستضافة والخدمات
- الاستضافة المعتمدة: Cloudflare Workers.
- المصادقة والبيانات: Supabase.
- لا يُستخدم GitHub Pages أو Vercel أو Netlify كوجهة نشر.
- ملفات CSS والشعار أصول واجهة تُنشر مع Worker، وليست بيانات تُخزّن في قاعدة Supabase.
- لا تضع مفاتيح الخدمة أو أسرار Telegram أو مفاتيح الخادم في Git أو في الواجهة.

## الهوية البصرية
- أخضر هادئ وأبيض ولمسات ذهبية رفيعة.
- الشعار: درع أخضر بإطار ذهبي رفيع، والنص «حرس الحدود» فقط.
- الخط العربي: Noto Naskh Arabic.
- مصدر الرموز الوحيد: `app/identity-tokens.css`، ولا تعرّف الواجهات الفرعية ألوانًا أو خطوطًا بديلة.
- جميع صفحات الويب تستخدم الهوية نفسها في الوضعين الفاتح والداكن.

## التطوير والتحقق
```sh
npm ci
npm test
npm run build:app
```

الاختبارات تستخدم Node.js `node:test`. لا تنفّذ أي migration أو تعديل Auth/RLS/Storage في Supabase من دون موافقة صريحة ومراجعة منفصلة.

## النشر
يُبنى Cloudflare Preview على فروع طلبات الدمج. نشر Production يدوي فقط من `main`، مع تأكيد صريح مستقل `confirm_production=true`.
