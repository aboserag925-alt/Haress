# الهوية البصرية الموحدة V2

## مصدر الهوية
- الرموز والألوان والخط: `app/identity-tokens.css`، وهو المصدر الوحيد للمتغيرات.
- المكونات والأنماط المشتركة: `app/identity-v2.css`.
- الصفحة الرئيسية ولوحة الإدارة وواجهة V3 تحمل الملفات المشتركة نفسها؛ ويقتصر `app/v3/v3.css` على تخطيط V3.
- واجهة V3 تستخدم الرموز والمكونات المشتركة، وتحتفظ فقط بقواعد التخطيط الخاصة بها في `app/v3/v3.css`.

## الهوية المعتمدة
- أخضر هادئ وأبيض، ولمسات ذهبية رفيعة.
- درع أخضر بإطار ذهبي رفيع، ونص «حرس الحدود» فقط.
- Noto Naskh Arabic هو الخط العربي الوحيد.
- RTL، الهاتف والكمبيوتر، الوضعان الفاتح والداكن.
- احترام `prefers-reduced-motion` وإمكانية الوصول.

## قواعد النظافة
- لا تعِد تعريف الألوان أو الخطوط خارج `identity-tokens.css`.
- لا تضف طبقات Tailwind أو CSS inline للواجهة.
- لا تستدعِ أصول الهوية القديمة.
- لا تغيّر المصادقة أو صلاحيات Supabase أو واجهات API أو وظائف المنصة أثناء تعديل العرض.
