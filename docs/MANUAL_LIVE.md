# البث المباشر اليدوي — app/ + Node

## حدود التنفيذ
- الواجهة الحالية في `app/` وخادم Node الموجود في `server/` فقط؛ لا Next.js ولا React.
- الحالة مصدرها الوحيد `public.live_state` بسجل singleton ثابت `id = 1`.
- جدول `broadcast_schedule` مؤجل عمدًا.
- لا يضمّن الموقع مشغلًا داخل الصفحة في هذه المرحلة؛ يفتح رابطًا خارجيًا فقط. هذا هو الخيار المحافظ لأن موفري القائمة الحالية لم يُعتمد لهم embed آمن.
- اكتشاف البث الآلي وحزمة Worker القديمة أزيلت؛ لا مفاتيح منصة فيديو ولا مفاتيح مزود خارجي مطلوبة.

## Migration
`supabase/migrations/20261111_live_state.sql` ينشئ الجدول idempotently ويزرع السجل الثابت عند غيابه. يمنح anon/authenticated قراءة أعمدة الحالة العامة فقط، ولا يمنح أي كتابة للمتصفح. يمنح service_role صلاحيات الخادم. لا تنفّذ Migration من CI أو من هذا الفرع؛ يلزم مراجعة وموافقة منفصلة قبل أي SQL على الإنتاج.

## API
- `GET /api/live/state`: عام، يقرأ الأعمدة العامة بمفتاح anon، مع ذاكرة خادم 30 ثانية وترويسة Cache-Control لمدة 30 ثانية.
- `GET /api/live`: توافق قديم `{ live, videoId: null }` ويعكس الحالة نفسها.
- `POST /api/admin/live`: Bearer session من Supabase Auth، تحقق خادمي من `admin_users`، وفحص Origin/CSRF، والتحقق من JSON والرابط.
- `LIVE_ALLOWED_HOSTS`: قائمة نطاقات مفصولة بفواصل. الافتراضي المحافظ: `tiktok.com,facebook.com,t.me`. يُقبل النطاق الأساسي أو أحد نطاقاته الفرعية فقط، وHTTPS فقط، دون بيانات دخول أو منفذ غير قياسي.
- التحديث يستخدم PostgREST upsert على المفتاح الثابت `id=1` مع `resolution=merge-duplicates`؛ لا يوجد حذف ثم إدخال.
- يحاول الخادم تسجيل `live_state.updated` في `audit_log` بشكل best-effort؛ لا يفترض schema غير موثق، ولا يفشل حفظ الحالة إذا كان الجدول غير موجود.

## الواجهة
- `app/live.html`: تحديث كل 60 ثانية وعند `visibilitychange`.
- `app/live-admin.html`: تسجيل دخول المشرف، تشغيل/إيقاف، رابط وعنوان.
- `app/live-client.js`: تحقق مستقل من نطاقات HTTPS قبل إنشاء رابط المشاهدة.
- قسم البث في التطبيق الحالي يعرض الحالة ورابط صفحة البث.
- جميع روابط المشاهدة الخارجية تستخدم `target=_blank` و`rel=noopener noreferrer`; لا يوجد iframe.

## PWA وCI
- `app/sw.js` يستخدم `ahl-athar-v6`، يضمّن صفحات البث الجديدة، ويحذف مخابئ `ahl-athar-*` القديمة عند التفعيل.
- إشعار التحديث وزر التفعيل اليدوي الموجودان في التطبيق محفوظان.
- CI يشغّل `npm test` و`npm run build` و`npm run check:secure`.

## قرارات محافظة موثقة
- لم تُعتمد نطاقات إضافية خارج الافتراضية المذكورة.
- لم تُفعّل embeds لأي مزود؛ المشاهدة خارجية فقط.
- بقي تكامل Gemini الخاص بمسودات الأسئلة كما هو لأنه منفصل عن اكتشاف البث؛ أزيلت آلية الكشف التلقائي القديمة بالكامل.
- فشل تسجيل `audit_log` لا يلغي تحديث الحالة، لأن schema الجدول غير مثبت في المستودع.
- لا تغيير في إعدادات الإنتاج أو متغيراته، ولا تنفيذ SQL، ولا merge أو deploy.
