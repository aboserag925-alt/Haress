# قوالب رسائل Supabase Auth — الهوية V2

هذه القوالب جاهزة للنسخ إلى **Supabase Dashboard → Authentication → Email Templates** لكل مشروع على حدة.

## الملفات والموضوعات

| الملف | نوع القالب | الموضوع المقترح |
|---|---|---|
| `confirmation.html` | Confirm signup | تأكيد البريد الإلكتروني — حرس الحدود |
| `recovery.html` | Reset password | إعادة تعيين كلمة المرور — حرس الحدود |
| `invite.html` | Invite user | دعوة للانضمام — حرس الحدود |
| `magic_link.html` | Magic Link | رابط تسجيل الدخول — حرس الحدود |
| `email_change.html` | Change Email Address | تأكيد تغيير البريد الإلكتروني — حرس الحدود |
| `reauthentication.html` | Reauthentication | رمز التحقق — حرس الحدود |

## تطبيقها على المشاريع المستضافة

1. افتح مشروع Supabase المقصود في لوحة التحكم.
2. انتقل إلى Authentication → Email Templates.
3. افتح نوع الرسالة المقابل، والصق محتوى الملف في محرر HTML، ثم ضع الموضوع المقترح.
4. احفظ واختبر كل تدفق برسالة اختبار قبل اعتماد الإعداد.
5. كرر الإجراء في مشروع Test أولًا، ثم Production بعد مراجعة نتيجة الاختبار.

**تنبيه:** ملفات القوالب هنا مصدر محفوظ في Git فقط. لم يتم تعديل إعدادات Auth في أي مشروع، ولم يتم إرسال رسائل، أو تغيير SMTP، أو تشغيل migrations. موصل Supabase المتاح في هذه الجلسة لا يوفر واجهة لتعديل Email Templates المستضافة؛ لذلك يتطلب تطبيقها الفعلي لصقها في لوحة Supabase. لا تغيّر إعدادات SMTP أو Site URL أو Redirect URLs ضمن هذه الخطوة.

## متغيرات القوالب

تستخدم القوالب المتغيرات الرسمية:
- `{{ .ConfirmationURL }}` لروابط التأكيد والاستعادة والدعوة والدخول وتغيير البريد.
- `{{ .Token }}` لرمز إعادة التحقق.

تعتمد ألوان القوالب على هوية V2 الخضراء والبيضاء والذهبية، وتستخدم خطوط النظام لثبات العرض في برامج البريد.
